# Java KB: правила для агентов

База для подготовки к собеседованиям на Java backend, уровень middle+ с выходом на senior. Пользователь изучает темы и повторяет вопросы. Изменения в базе он просит сделать агента.

## Где что лежит

- `assets/topics.js` — дерево тем, порядок, `scope`, частота и статус.
- `topics/<id>.html` — заполненная тема; `topics/_template.html` — заготовка.
- `assets/search.js` — генерируемый индекс, руками не править.
- `assets/kb.js`, `assets/kb.css` — движок. При работе с содержимым его не трогай.
- `tools/build_search.py`, `tools/check_kb.py` — сборка индекса и проверка связей.

## Что читать перед работой

1. Для любого изменения прочитай `docs/authoring/common.md` и `docs/authoring/validation.md`.
2. При создании или правке страницы прочитай `docs/authoring/blocks.md` и файл типа: `concept.md`, `technology.md` или `algorithms.md` в той же папке. Прочитай указанный там эталон целиком.
3. Если тип темы пока не описан, возьми ближайший эталон и скажи пользователю, что тип новый.

## Неподвижные правила

- У заполненной темы не меняй `id`: по нему хранятся прогресс и ссылки. Существующие `id` шагов и карточек тоже сохраняй.
- `status: 'ready'` ставит только пользователь или агент по его прямой просьбе.
- При перестройке папки по курсу, книге или роадмапу сначала покажи новое дерево и судьбу старых тем, дождись согласия пользователя. Правила — в `common.md`.
- После любой правки собери поиск, проверь структуру и страницу в браузере, сделай один коммит на одну тему или перестройку. Подробности — в `validation.md`.
