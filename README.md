# Java KB

Библиотека тем для подготовки к собеседованиям на Java backend. Открой `index.html` в браузере, сборка не нужна.

## Как читать

- Главная — колонки по дереву тем, как в Finder. Стрелки двигают выбор, Enter или двойной клик открывает тему. Путь сохраняется в адресе, например `index.html#backend/messaging/kafka/kafka-dlq`.
- Поиск по темам, шагам уроков и вопросам — в шапке, клавиша `/`.
- Тема — это урок по шагам, а после него вопросы с собеседования или задачи. Вопросы свёрнуты: сначала ответь сам, потом открой и сравни. Пошаговые схемы листаются кнопками или стрелками.
- Оценка «не знаю / плаваю / объясню» (у задач — «не решил / с подсказкой / решил») назначает повторение через 1, 3 и 7 → 21 → 60 дней. «К повторению» на главной собирает карточки, у которых подошёл срок.
- Тему целиком можно поставить на повторение кнопкой «Добавить в повторение» в шапке темы: она сразу попадает в «К повторению». После повторения отметь «не помню / плаваю / помню», и тема вернётся через те же 1, 3, 7 → 21 → 60 дней.

Прогресс хранится в `localStorage` браузера.

## Как менять

Кнопок «добавить» в базе нет: всё меняется через агента обычными словами. Агент знает правила из [AGENTS.md](AGENTS.md). Примеры просьб:

- «Добавь в Backend › Сообщения тему про Kafka Streams», «перенеси Records и enum в Основы языка», «убери тему Cassandra».
- «Перестрой папку Многопоточность по курсу X» — агент предложит структуру и применит её после твоего согласия.
- «Заполни тему JMM по книге Java Concurrency in Practice, главы 3 и 16» — источник можно не называть, тогда агент выберет сам.
- «Добавь в Kafka › Основы вопрос про compaction», «сделай пошаговую схему для rebalance».
- Читаешь тему, возникает вопрос — просто спроси агента в чате. Если ответ стоит сохранить, скажи «допиши в тему». Агент встроит его в урок или добавит в «Твои вопросы» внизу страницы.

Статус «готово» у темы ставишь ты: скажи агенту, что тема проверена.
