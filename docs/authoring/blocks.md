# Блоки страницы

Справочник разметки. Что писать и насколько глубоко — в `quality.md`, как рисовать — в `illustrations.md`. Заготовка со всеми блоками — `topics/_template.html`.

## Каркас

```html
<main class="page">
  <header class="topic-head"><h1>Тема</h1></header>
  <div class="lesson"> шаги и итог </div>
  <section class="interview" id="interview"><h2>На собеседовании</h2> карточки </section>
  <div class="qa"> ответы на вопросы пользователя, при создании пустой </div>
  <div class="refs"><ul> источники </ul></div>
</main>
```

В алгоритмических темах и темах-практикумах вторая часть называется «Задачи»: `<h2>Задачи</h2>`.

## Блоки

| Блок | Разметка | Где | Для чего |
|---|---|---|---|
| Шаг урока | `section.step#id > h2` | `.lesson` | одна мысль урока; номер и оглавление добавит скрипт |
| Подзаголовок | `h3` | шаг | шаг из нескольких частей |
| Аналогия | `p.idea` | шаг | 2–4 предложения, только точная, одна на урок |
| Код и вывод | `pre > code.language-java`, затем `pre.out` | шаг, карточка | вывод скрипт спрячет под «Что выведет?» |
| Команды, логи, конфиги | `pre > code.language-text` (`bash`, `yaml`, `sql`, `json`) | шаг, карточка | запуск, флаги, отрывок GC-лога |
| Таблица | `table.mx` | где угодно | сравнение вариантов, значения по умолчанию |
| Заблуждение | `div.trap > p.myth + p.fact` | шаг | прямо там, где оно возникает |
| Заметка | `div.note.tip`, `div.note.warn`, `div.note.exp` | шаг | «Совет», «Ловушка» в проде, «Из опыта» |
| Глубже | `details.deep > summary` | шаг | исходники, байткод, история; урок читается без него |
| Схема | `figure.fig > div.fig-box > svg.dg` + `figcaption` | шаг | структура, связи, сравнение (`illustrations.md`) |
| Пошаговая схема | `figure.fig.play` + `ol.play-steps` | шаг | процесс во времени (`illustrations.md`) |
| Итог | `div.summary > ul` | конец `.lesson` | 3–6 мыслей, которые стоит помнить через месяц |
| Вопрос | `article.q#id[data-freq]` | `.interview` | раздел «Вопрос» ниже |
| Задача | `article.q#id[data-freq][data-type="task"]` | `.interview` | раздел «Задача» ниже |
| Проверка | `div.check > details[data-kind]` | карточка | `задача`, `уточнение`, `ревью` |
| Ответ на вопрос пользователя | `details.qa-item` | `.qa` | сценарий «Пользователь спрашивает» в `workflow.md` |
| Источник | `li` | `.refs ul` | что и где смотреть |

Заголовок шага `h2` — только текст, без `<code>` и другой разметки. Номер шага рисуется через flex, и на узком экране вложенный `<code>` рассыпается в столбик по букве. Имена методов и классов в заголовке пиши обычным текстом.

Подписи блоков («Разбор», «Проверь себя», «Коротко», «Твои вопросы», «Вывод»), путь по папкам, `scope`, номера шагов, оглавление, переключатель Senior, повторение и самооценку рисует `kb.js`. В HTML их не пиши.

Нужен блок, которого нет в таблице? Сначала собери его из существующих. Не получается — предложи пользователю, а не придумывай новый класс в одной теме.

## Вопрос

```html
<article class="q" id="card-id" data-freq="3">
  <h3>Вопрос так, как его задают вслух</h3>
  <div class="answer">
    <div data-level="middle">
      <p>Определение и механизм, от первого лица.</p>
      <p>Практический смысл на примере из backend.</p>
    </div>
    <div data-level="senior">
      <ul><li>Что добавить, если копают глубже.</li></ul>
    </div>
  </div>
  <div class="check">
    <details data-kind="задача">
      <summary>Что выведет этот код?</summary>
      <pre><code class="language-java">…</code></pre>
      <pre class="out">…</pre>
      <p>Почему так.</p>
    </details>
    <details data-kind="ревью">
      <summary>Найди ошибку в этом коде</summary>
      <pre><code class="language-java">…</code></pre>
      <p>Где ошибка, чем опасна, как исправить.</p>
    </details>
    <details data-kind="уточнение">
      <summary>Что интервьюер спросит следом</summary>
      <p>Ответ в 2–6 предложений.</p>
    </details>
  </div>
</article>
```

`id` карточки и `data-freq` обязательны. После публикации `id` не меняется: к нему привязан прогресс.

## Задача

Для алгоритмических тем и практикумов (SQL, Stream API).

```html
<article class="q" id="card-id" data-freq="3" data-type="task">
  <h3>Название задачи</h3>
  <div class="task">
    <p>Условие.</p>
    <pre class="io">вход → выход</pre>
    <p class="src">LeetCode 3 · medium · нужно O(n)</p>
    <details><summary>Заготовка: Name.java</summary><pre><code class="language-java">…</code></pre></details>
  </div>
  <div class="hints">
    <details><summary>Подсказка 1</summary><p>…</p></details>
    <details><summary>Подсказка 2</summary><p>…</p></details>
  </div>
  <details class="solution"><summary>Решение</summary> идея, код, сложность </details>
  <div class="check">…</div>
</article>
```

- Заготовка — полный файл, который запускается как `java Name.java`: метод с пустым телом и `main` с проверками через `check(got, want)`. Среди проверок — крайние случаи и случай, на котором ломается наивное решение.
- Решение подставь в заготовку и прогони: все проверки должны печатать OK.
- 2–3 подсказки: первая называет паттерн или переформулирует задачу, последняя почти даёт решение.
- Для SQL-задач вместо заготовки — схема таблиц и данные (`CREATE TABLE`, `INSERT`), ожидаемый результат — таблицей. Запрос проверь в PostgreSQL.

## Ответ на вопрос пользователя

```html
<details class="qa-item">
  <summary>Вопрос, сформулированный ясно <time datetime="2026-09-25">25.09.2026</time></summary>
  <p>Ответ: 3–10 предложений, можно список, код или схему.</p>
</details>
```

## Источник

```html
<li><a href="https://…">Название</a> — основа урока: главы 3 и 16, что там смотреть.</li>
```

2–5 пунктов. Источник, по которому построен урок, идёт первым с пометкой «основа урока». У каждого пункта — что именно там смотреть: глава, раздел, минута доклада.

## Форматирование HTML

Страницу будут дописывать другие агенты, поэтому HTML должен читаться глазами.

- Один блок — одна строка или несколько строк с отступом в 2 пробела по вложенности, как в `_template.html` и эталонах.
- Абзац — отдельная строка `<p>…</p>`. Не склеивай шаг в одну строку.
- В SVG — одна фигура или короткая группа на строку, с комментариями к частям схемы.
- Строки длиннее 1000 символов валидатор считает признаком сжатого HTML.
- Спецсимволы в коде экранируй: `&lt;`, `&gt;`, `&amp;`.
