# Концепция

Эталон: `topics/polymorphism.html`. Прочитай его целиком перед заполнением темы этого типа. Примеры: ООП, SOLID, транзакции.

План урока: конкретная задача → идея на том же примере → механика → практический смысл → границы. Во второй части — «На собеседовании» с вопросами. План — ориентир; если урок строится по названному пользователем источнику, порядок источника важнее.

Сохраняй одну линию рассуждения и один сквозной пример. Детали, без которых основная мысль понятна, размещай в `details.deep` или проверках карточек.
