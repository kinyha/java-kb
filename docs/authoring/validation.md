# Проверка после правки

Выполни эти шаги после любого сценария изменения базы.

## В конце любой правки

1. `python3 tools/build_search.py` и `python3 tools/check_kb.py`.
2. Проверка в браузере (раздел «Проверка» ниже).
3. Коммит: одна тема или одна перестройка — один коммит, в сообщении — что и где изменилось.
4. Коротко скажи пользователю, что сделал и где это найти, например «Java › Многопоточность › JMM, шаг 3».

## Проверка

Из корня проекта:

```bash
python3 -m http.server 8791 --directory .
```

Открой `http://localhost:8791/topics/<id>.html`: шаги пронумерованы и есть в оглавлении, вывод кода спрятан, вопросы свёрнуты и открываются, пошаговые схемы листаются, в консоли нет ошибок. На главной тема видна в своей папке, поиск её находит. Страницы работают и без сервера, через `file://`.
