# Abstraction demos

Примеры к теме Java › Abstraction. JDK 21, без зависимостей.

```bash
cd examples/abstraction
java DispatchDemo.java   # какой default выполнится, шаблонный метод в абстрактном классе
java RulesDemo.java      # что javac говорит о конфликтах default, полях и static-методах интерфейса
./evolve.sh              # старый класс-реализация с новым default и новым абстрактным методом
```
