# Classes & Objects demos

Примеры к теме Java › Classes & Objects. JDK 21, без зависимостей.

```bash
cd examples/classes-objects
java InitOrderDemo.java   # порядок инициализации класса и объекта, ленивая инициализация
java StateDemo.java       # передача по значению, общее static-поле, final-ссылка
./javap.sh                # куда компилятор кладёт инициализаторы полей
```
