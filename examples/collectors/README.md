# Collectors demos

Примеры к теме Java › Collectors. JDK 21, без зависимостей.

```bash
cd examples/collectors
java CollectorsDemo.java   # toMap с дубликатами и null, groupingBy с downstream, partitioningBy, teeing, Collector.of
java ReportDemo.java       # топ по значению, топ-N в группе, частоты, индекс с порядком
```
