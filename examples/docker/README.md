# Docker demo

Пример к теме DevOps › Docker: образы для мини-сервиса на JDK HttpServer, кеш слоёв, лимиты контейнера и PID 1. Нужен Docker.

```bash
./examples/docker/docker.sh
```

Скрипт создаёт в libs/ файл на 40 МБ для опыта с кешем слоёв (в git не попадает). Размеры образов зависят от архитектуры; на странице — arm64.
