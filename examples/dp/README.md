# Dynamic Programming

JDK 21, без сборки и зависимостей. Из корня репозитория:

```bash
java examples/dp/StairsDemo.java
java examples/dp/CoinsDemo.java
java examples/dp/KnapsackDemo.java
java examples/dp/LcsDemo.java
java examples/dp/ClimbStairs.java
java examples/dp/CoinChange.java
java examples/dp/Knapsack.java
java examples/dp/Lcs.java
```

Четыре Demo дают 12 опытов. Четыре задачи содержат готовые решения с
31 проверкой; ошибка вызывает AssertionError. Решение можно заменить
TODO из полной заготовки на странице.

Лестница: шаги 1/2, пустой маршрут — один способ. Задача принимает 0..91
и возвращает long. Демо отдельно показывает переполнение int при n=46,
Math.addExact обнаруживает переполнение long при n=92.
calls включает все входы в функцию, включая попадания в готовые состояния.

Монеты: положительные номиналы, неограниченное количество, точная сумма.
В задаче amount 0..10000, пустые и повторные номиналы дополнительно
разрешены. Для подсчёта в CoinsDemo номиналы различны: одинаковые значения
иначе были бы разными типами выбора. Значок ∞ заменяет sentinel amount+1.

Рюкзак: 0/1, каждый предмет доступен один раз, capacity — верхняя граница
веса. Веса положительны, ценности неотрицательны, ответ помещается в int.
Демо ascending намеренно решает вариант с повтором; descending — 0/1.
Полная таблица нужна для восстановления items, при равенстве предмет
не берётся. Входные массивы сохраняются.

LCS: строки из ASCII, индексы относятся к char. Нужна подпоследовательность,
не непрерывная подстрока. При равенстве длин восстановление предпочитает
верхнюю клетку; другой tie-break может дать другой правильный ответ.
wrongDiagonal намеренно сохраняет уже обновлённую диагональ.

тайминги и внешняя инфраструктура отсутствуют.
