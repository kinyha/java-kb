# Encapsulation demos

Примеры к теме Java › Encapsulation. JDK 21, без зависимостей.

```bash
cd examples/encapsulation
java InvariantDemo.java   # сеттеры против операций с инвариантом
java CopiesDemo.java      # unmodifiableList и copyOf, изменяемый ключ, рефлексия и final
./modules.sh              # неэкспортированный пакет и глубокая рефлексия между модулями
```
