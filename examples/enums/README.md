# Enums demos

Примеры к теме Java › Enums. JDK 21, без зависимостей.

```bash
cd examples/enums
java --add-opens java.base/java.util=ALL-UNNAMED EnumDemo.java   # флаг нужен только для чтения битов EnumSet
./javap.sh                                                          # во что компилируется Channel.java
```
