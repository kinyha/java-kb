# Graphs: четыре опыта на JDK 21

Зависимости и сборка не нужны. Из этой папки:

```bash
java GraphWalkDemo.java
java CycleDemo.java
java DependenciesDemo.java
java WeightedRoutesDemo.java
```

Вывод на странице взят из запуска JetBrains Runtime 21.0.11+10-b1163.116.
Списки соседей сохраняют порядок добавления. В очереди Дейкстры равные цены
сравниваются дальше по номеру вершины, поэтому вывод воспроизводится.

## Что проверяют программы

- `GraphWalkDemo`: ориентированное ребро не создаёт обратное; изолированная
  вершина сохраняется. BFS помечает при добавлении и оставляет один из равных
  кратчайших путей. Путь к старту `[0]`, к недостижимой цели `[]`.
- `CycleDemo`: общий завершённый потомок не создаёт цикл, ребро к активному
  предку создаёт. Проверяются отдельная компонента, петля и цепочка 100 000
  вершин. Для цепочки используется явный стек с кадрами, а не рекурсия;
  конкретный порог StackOverflowError намеренно не измеряется.
- `DependenciesDemo`: Кан учитывает две предпосылки и независимую вершину.
  Остаток `[1, 3, 4]` включает цикл `1 -> 3 -> 1` и зависимую от него 4.
  Пустой граф имеет пустой топологический порядок.
- `WeightedRoutesDemo`: BFS минимизирует число рёбер, Дейкстра — сумму
  неотрицательных весов. В ленивой PriorityQueue устаревшие неизменяемые
  записи отбрасываются. Дополнительно показаны нулевой цикл, отклонение
  отрицательного веса и переполнение long.

## Условия учебного API

Все номера вершин корректны и лежат в `[0, n)`. Граф во время обхода не меняется.
Конструкторы специально оставлены одинаковыми и короткими, без проверки
пользовательского ввода. Для BFS и Дейкстры старт должен существовать; пустой
граф проверяется только в сортировке зависимостей.

`CycleDemo` останавливается сразу после обнаружения цикла. Массив цветов после
этого не используется: ранний выход оставляет активные кадры незавершёнными.
Печать `done edge` происходит как после возврата из дочернего вызова, так и при
встрече уже завершённой вершины.

`WeightedRoutesDemo` использует `Long.MAX_VALUE` как INF. Отрицательные веса
запрещены во всём входном графе. При переполнении любой проверяемой суммы или
получении ровно INF расчёт завершается с ArithmeticException. Это строгая
политика учебного API; она не пытается проигнорировать слишком дорогой обходной
маршрут, даже если где-то существует представимый более короткий путь.

На схеме Дейкстры очередь показана в порядке будущего извлечения. Это не
физический массив кучи и не порядок iterator() у PriorityQueue.

Полные задачи на острова, неявные графы и зависимости относятся к Graph Search.
Эти четыре программы доказывают механизм и границы структуры данных.
