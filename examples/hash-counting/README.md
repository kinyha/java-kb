# Arrays & Hashing: JDK 21

Все программы — отдельные файлы без внешних зависимостей. Из этой папки:

```bash
java PairDemo.java
java FrequencyDemo.java
java GroupingDemo.java
```

Вывод на странице взят из JetBrains Runtime 21.0.11+10-b1163.116.
LinkedHashMap и LinkedHashSet используются там, где порядок входит в условие
или нужен для воспроизводимой печати. Обычный HashMap не обещает порядок обхода.

`PairDemo` сравнивает перебор с памятью о предыдущем префиксе. Показывает
неправильную пару одного элемента с собой и переполнение int.

`FrequencyDemo` различает наличие, кратность и момент обнаружения дубля.
Строки из a…z используют массив 26 частот. Дополнительный опыт с Unicode
сравнивает корректные, но по-разному составленные суррогатные пары: одинаковый
набор char не означает одинаковый набор кодовых точек. Нормализация NFC показана
отдельно для é и e с комбинируемым акцентом; это явный выбор семантики.

`GroupingDemo` сравнивает сортированные и частотные подписи. Проверяет отсутствие
границ при склейке чисел, ссылочное равенство массива в record и совпадение
Arrays.hashCode у двух разных массивов. У полного ключа всё ещё должно быть
корректное equals; хеш один не определяет группу.

Решения задач со страницы:

```bash
java TwoSum.java
java ValidAnagram.java
java GroupAnagrams.java
java DuplicateIds.java
java LongestConsecutive.java
```

Каждое решение проходит main с теми же проверками, что в заготовке страницы:
TwoSum — 8, ValidAnagram — 7, GroupAnagrams — 6, DuplicateIds — 7,
LongestConsecutive — 9. Всего 37 проверок. При несовпадении программа бросает
AssertionError, поэтому FAIL не прячется за успешным кодом завершения.

Для самостоятельной работы скопируй полную заготовку с HTML, сохрани под
указанным именем и замени тело целевого метода. На странице раскрывается именно
метод решения: его можно вставить вместо заглушки, сохранив imports, main и check.

Условия: входы без null. ValidAnagram и GroupAnagrams принимают только a…z.
TwoSum поддерживает весь диапазон int; разность вычисляется в long, ответ
пустой при отсутствии пары, иначе минимальный правый индекс и затем левый.
DuplicateIds сравнивает id точным String.equals и выдаёт каждый дубль один раз
по его второму появлению. LongestConsecutive не соединяет MAX_VALUE с MIN_VALUE
и не меняет исходный массив. Все задачи работают в одном потоке со стабильным
входом; это алгоритмы обработки выгрузки, а не хранилище платёжной идемпотентности.
