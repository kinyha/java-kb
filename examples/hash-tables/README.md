# Hash Tables: маршруты поиска платежей

Три независимых single-file демо. Нужен JDK 21, зависимости и сборка не нужны.
Запускайте из этой папки:

```bash
java HashContractDemo.java
java ChainingDemo.java
java ProbingDemo.java
```

Проверено на JetBrains Runtime 21.0.11+10-b1163.116. Для запуска с этим JDK
можно заменить `java` абсолютным путём к его `bin/java`.

`HashContractDemo` печатает четыре блока: совпадение полного хеша Aa/BB,
совпадение бакета при разных хешах и отрицательный индекс, область уникальности
ключа продавец+запрос, изменение ключа после вставки в HashMap. Последний опыт
показывает устройство JDK 21: HashMap хранит полный хеш в узле. После изменения
1 на 33 номер бакета при ёмкости 16 остался прежним, но get с тем же объектом
вернул null; обход всё ещё видит запись. Это демонстрация ошибки, а не допустимый
способ изменения ключей Map.

`ChainingDemo` печатает два блока. Сначала бакет 1 содержит цепочку 9 → 5 → 1.
Счётчик checks показывает число сравнений при get. Затем четвёртая запись
пересекает учебный порог 0.75, массив растёт 4 → 8. Порядок переноса: 13, 9, 5, 1.
Итоговые цепочки: бакет 1 — 1 → 9, бакет 5 — 5 → 13. Порог и удвоение здесь
выбраны для объяснения; это собственная реализация, не копия HashMap JDK.

`ProbingDemo` печатает четыре блока. Три платежа с home = 1 занимают слоты 1, 2, 3.
Намеренная ошибочная очистка слота 2 скрывает 17. Правильное удаление оставляет D,
обновление 17 проходит мимо D, новая запись 25 переиспользует D после проверки
остатка маршрута. Последний блок показывает восемь проб на отсутствующем ключе
при семи живых записях в восьми слотах. Таблица фиксированная, не растёт;
при полном заполнении put нового ключа бросает IllegalStateException.

В обеих учебных таблицах ключи — int, значения — ненулевые String. null в результате
get означает отсутствие. Хешом служит само числовое значение, индексом — floorMod:
так легко предсказать коллизии. Эта функция намеренно выбрана для наглядности,
а не как рекомендация для произвольных данных. Счётчики показывают работу
алгоритма, не измеряют производительность JDK или время CPU.

На [странице](../../topics/hash-tables.html) приведены фрагменты этих файлов и все
содержательные строки вывода. Названия блоков в консоли лишь разделяют опыты.
