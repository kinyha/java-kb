# Heap Sort

Из корня репозитория, на JDK 21, без зависимостей и сборки:

```bash
java examples/heap-sort/HeapSortDemo.java
java examples/heap-sort/RestoreRoot.java
java examples/heap-sort/HeapSuffix.java
java examples/heap-sort/PaymentHeapSort.java
```

`HeapSortDemo` печатает трассировки урока и счётчики сравнений.
Остальные файлы — решения трёх задач с проверками; заготовки находятся на странице.
Проверочный код копирует массивы и строит эталоны. Алгоритмы изменяют исходный
массив и работают с постоянной дополнительной памятью.
