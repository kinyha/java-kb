# Intervals · JDK 21

Из этой папки, без сборки и зависимостей:

```bash
java MergeDemo.java
java PairDemo.java
java RoomsDemo.java
java MergeIntervals.java
java InsertInterval.java
java Intersections.java
java MeetingRooms.java
```

Проверено на JBR 21.0.11. MergeDemo и PairDemo работают с закрытыми [left,right], точка [x,x] допустима. RoomsDemo и MeetingRooms работают с полуоткрытыми [start,end) положительной длины: законченный в t платёж освобождает слот для начинающегося в t. Целые числа — единая шкала времени, не часы в разных часовых поясах.

MergeDemo показывает касание границ, сокращение конца ошибочной версией при вложении, сохранение исходного порядка, разницу между внешним clone и копированием строк, переполнение вычитания в comparator и длине. PairDemo показывает расширяющуюся границу вставки и продвижение меньшего end при пересечениях. Последний вызов намеренно нарушает условие отдельности интервалов внутри одного входа и теряет пересечение: это контрпример к переносу алгоритма на произвольный список.

RoomsDemo сравнивает максимум heap с его размером после последнего старта, порядок событий при равном времени и компоненты покрытия с количеством одновременно занятых слотов. Печать heap предварительно сортирует копию окончаний; итерация PriorityQueue сама по себе отсортированный порядок не обещает.

Четыре файла задач содержат решения и проверки страницы. Ошибка завершает запуск AssertionError. Проверяются крайние границы int, касание, вложение, пустые входы, сохранение исходных массивов. Задачи с возвращаемыми интервалами также требуют собственные строки результата без ссылок на строки входа. InsertInterval и Intersections принимают уже отсортированные и попарно непересекающиеся закрытые интервалы внутри каждого входа.

Все методы сохраняют вход. Сортировка меняет только клонированный внешний массив, а результат создаёт новые строки. Память входа, результата, сортировки и диагностической печати оцениваются отдельно в уроке.
