# Operating Systems demos

ProcessDemo требует JDK 21 и запускается без сборки. Режим signals предназначен
для Unix: обычное завершение процесса должно поддерживаться реализацией Java.

```bash
cd examples/os
java ProcessDemo.java threads
java ProcessDemo.java pipe
java ProcessDemo.java signals
```

threads показывает общую память и локальное завершение рабочего потока из-за
исключения. pipe запускает отдельную JVM и намеренно не читает её stderr до
истечения короткого ожидания. Затем читает все 32 МиБ и получает завершение.
signals сравнивает остановку дочерней JVM обычным и принудительным способом через
ProcessHandle. Объект Process сохраняется для ожидания и чтения вывода shutdown hook.
Процессы принадлежат самому демо; после любого сбоя они принудительно завершаются.

ForkDemo — небольшой POSIX-пример на C: Java не предоставляет fork для своей памяти.
Нужен C-компилятор; проверен на macOS, использует общие для Unix fork/pipe/waitpid.

```bash
cc -std=c11 -Wall -Wextra -Werror ForkDemo.c -o ForkDemo
./ForkDemo copy
./ForkDemo eof
```

copy сравнивает независимую переменную после fork с общей позицией унаследованного
открытого файла. Родитель ждёт ребёнка перед чтением, поэтому порядок задан явно.
eof доказывает, что завершения ребёнка недостаточно для EOF: родитель тоже должен
закрыть собственную копию конца записи. Объём данных мал, блокирующих ожиданий
незавершённого протокола нет. Обе программы не нужны для запуска Java-примеров.

MemoryDemo предназначен для Linux: измеряет отдельное отображение через
/proc/self/smaps. Проверен в Linux-контейнере с базовой страницей 4096 байт.
Размер программа получает через sysconf, а для отображения отключает transparent
huge pages, чтобы сравнить одну базовую страницу до и после записи.

```bash
cc -std=c11 -Wall -Wextra -Werror MemoryDemo.c -o MemoryDemo
./MemoryDemo resident
./MemoryDemo cow
./MemoryDemo protect
```

resident резервирует 1024 страницы, читает первый байт каждой и затем записывает
его. RSS относится только к этому диапазону, minor/major faults — к процессу.
cow измеряет RSS/PSS одной страницы в ребёнке до и после записи; родитель ждёт
его выхода, проверяет своё значение и сравнивает числовые виртуальные адреса.
protect меняет права страницы у ребёнка на чтение и получает SIGSEGV при записи;
родитель проверяет сигнал через waitpid. Core dump у ребёнка отключён. Защитные
страницы отделяют измеряемый VMA от соседних отображений. Это короткие процессы
с несколькими МиБ памяти; swap и OOM в демо не вызываются.
