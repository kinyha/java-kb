# Payments: локальные модели стадий и наблюдения

JDK 21, без библиотек и сетевых сервисов. Из корня репозитория:

```bash
java -version # Нужен JDK 21.
java -ea examples/payments-domain/StageDemo.java
java -ea examples/payments-domain/ClearingDemo.java
java -ea examples/payments-domain/StatusFactsDemo.java
java -ea examples/payments-domain/RefundDemo.java
```

- `StageDemo`: авторизация не создаёт выплату; принятие команды не подтверждает
  capture; capture, получение расчёта провайдером и выплата продавцу раздельны.
  Комиссия 300 копеек — вымышленное условие примера.
- `ClearingDemo`: встречные позиции A → B 200 RUB, B → A 50 RUB дают
  двустороннюю расчётную позицию A → B 150 RUB. Нет комиссий и FX.
- `StatusFactsDemo`: неизвестный результат после таймаута, события не по порядку,
  повтор возвратного события и его конфликт, отдельное состояние спора.
- `RefundDemo`: подтверждённые и ожидающие возвраты вместе ограничивают
  сумму новой заявки; подтверждённый отказ освобождает сумму.

Целые суммы — копейки RUB, данные вымышлены, вывод детерминирован.
Это модели одного потока в памяти. Банки, PSP, SWIFT, СБП не вызываются.
Имена учебных событий не являются общим протоколом этих систем.
Демо не реализуют ledger, транзакции БД, сетевую проверку уведомлений,
полный регламент карточной сети или гарантии провайдера.

В `StageDemo` порядок известен автору сценария. Нулевые суммы показывают,
что соответствующее действие в этом сценарии ещё не исполнялось.
В `StatusFactsDemo` отсутствие сообщения представлено `null`: неизвестно.
Его модель хранит по одному итогу авторизации, полного capture и расчёта;
для нескольких capture, изменения авторизации и корректировок нужны
отдельные операции и более полный набор правил. Повтор узнаётся по event.id.
Для разных сообщений об одном возврате требуется также идентификатор возврата.
Открытие спора не моделирует окончательный chargeback.

В `RefundDemo` состояние FAILED обозначает подтверждённый отказ,
а не локальный таймаут. Проверка доступной суммы и создание заявки
в рабочей системе должны выполняться атомарно.
