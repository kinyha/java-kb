# Load testing demo

Пример к теме DevOps › Load Testing: k6 1.3 в Docker против Service.java на хосте. Нужны JDK 21 и Docker.

```bash
./examples/performance/load.sh
```

Прогон длится около четырёх минут. Генератор и сервис работают на одной машине, поэтому точки за коленом показывают характер, а не точные числа.
