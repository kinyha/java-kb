# Team Process

JDK 21, без сборки и инфраструктуры. Из корня репозитория:

```bash
java examples/process/FlowDemo.java
java examples/process/ForecastDemo.java
```

Всего 4 блока вывода. Поддерживается -ea; locale ROOT фиксирует точку в числах.
Вывод снят на JBR 21.0.11.

FlowDemo — детерминированная учебная очередь: 12 заявок в момент0,
один разработчик (код1 день), один проверяющий (проверка3 дня), FIFO,
без дефектов и возвратов. WIP от начала кода до конца проверки включает
ожидание проверяющего. Завершение в момент start освобождает место до
нового начала. WIP=2 уменьшает начатую очередь; время готовности всех
12 заявок остаётся37. Lead time от заявки0 не сокращается.
Снимок blocked не часть симуляции очереди: это отдельные карточки P1/P2/P3
на условный день10; все начаты и не завершены. P1 заблокирована с возрастом8.

ForecastDemo — точный перебор64 упорядоченных пар из8 исторических недель,
с повторным выбором той же недели. Модель предполагает независимость и
применимость этой истории к будущему, сопоставимые карточки и стабильную
мощность. model share — доля сценариев этой модели, не реальная вероятность
обещанного срока. История учебная, не статистика проекта пользователя.

retry-task.md и adr-0001-payment-key.md — вымышленные учебные документы.
ADR имеет статус «Предложено»: гарантии конкретного банка не установлены.
Тесты и рантайм-код платежей в эту тему не входят; схема документации
показывает связь требований, решения и места проверки.
