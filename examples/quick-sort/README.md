# Quick Sort

Single-file Java, JDK 21. Запускай из корня репозитория:

```bash
java examples/quick-sort/QuickSortDemo.java
java examples/quick-sort/ColorsDemo.java
java examples/quick-sort/KthLargestDemo.java
java examples/quick-sort/SubrangeSortDemo.java
```

QuickSortDemo показывает разбиение, шесть состояний трёхстороннего прохода,
число итераций внутренних циклов, глубину нашего метода sort, нарушение
стабильности и выбор k-го элемента. Счётчики не являются замером времени.
Глубина включает вызов на пустой меньшей стороне, поэтому одинаковые данные
дают maxDepth=2. Seed 42 делает учебный запуск воспроизводимым.

Остальные файлы — проверенные решения трёх задач страницы. При решении
замени отмеченный метод пустой заготовки кодом решения, оставив main и check.
Данные 0/1/2 в первой задаче гарантируются условием. select сохраняет входной
массив через clone; сортировка диапазона меняет только [lo, hi).
