# Chat System demo

Пример к теме System Design › Case Studies › Chat System. JDK 21, без зависимостей.

```bash
java examples/sd-chat/ChatDemo.java
```

Сервер чата, шлюзы и сеть смоделированы в одном процессе, без настоящих WebSocket и базы.

1. Порядок по часам отправителя, по часам двух экземпляров сервера и по `seq` чата.
2. Групповой чат: два отправителя, два получателя, доставка каждому получателю — отдельная задача со случайной задержкой 0–2 мс. Сколько прогонов дали разный порядок на экранах и сколько дыр в `seq` заметил клиент. Последняя строка этого раздела меняется от запуска.
3. Потерянный ack и повтор с тем же `client_msg_id`: без дедупликации и с ней.
4. Курсоры устройств, `delivered_up_to` и `read_up_to`: телефон и ноутбук, офлайн и синхронизация.
