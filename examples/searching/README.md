# Binary Search · JDK 21

Из этой папки, без сборки и зависимостей:

```bash
java SortedDemo.java
java CapacityDemo.java
java RotatedDemo.java
java IntegerRoot.java
java EqualRange.java
java RotatedSearch.java
java ShipCapacity.java
```

Проверено на JBR 21.0.11. Три демо дают вывод из урока; четыре остальных файла — решения задач с проверками из заготовок страницы. Ошибка проверки завершает запуск с `AssertionError`.

`SortedDemo`: три проверки вместо семи; lower/upper bound дают полуинтервал равных элементов; позиция вставки не доказывает наличие элемента; `Arrays.binarySearch` может вернуть среднюю копию и кодирует отсутствие как `-(insertionPoint + 1)`; диапазон API возвращает абсолютный индекс. Переполнение середины воспроизводится арифметикой без гигантского массива. Конкретный индекс найденной копии — наблюдение этого запуска, а не гарантия API.

`CapacityDemo`: пакеты идут в исходном порядке, вместимость — упорядоченное пространство ответов. Жадная проверка даёт минимальное число дней для выбранной вместимости. Поиск находит первый допустимый ответ, сумма и границы `long`. Вес неотрицательный, `days >= 1`, пустой вход требует вместимости 0.

`RotatedDemo`: массив получен циклическим сдвигом отсортированного. Без дублей хотя бы одна половина отсортирована, за шаг исключается половина области. Дубли могут скрыть место разрыва: одинаковые края тогда сокращаются по одному, худшее время O(n).

`IntegerRoot`: вход неотрицательный `int`; квадрат и правая граница считаются в `long`. `EqualRange` получает отсортированный массив, возвращает первый и последний включённые индексы либо `[-1, -1]`. `RotatedSearch` принимает только различные значения. `ShipCapacity` допускает неотрицательные веса, требует положительное число дней, возвращает `long` и сохраняет порядок. Все входы не `null`.

Оценки времени относятся к алгоритмам без диагностической печати. Для поиска по ответу учитывается цена каждого полного прохода проверки.
