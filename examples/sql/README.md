# Queries: настоящий PostgreSQL

Из корня репозитория: `bash examples/sql/run.sh`.

Нужен Docker. Скрипт запускает отдельный `postgres:17.11-alpine` без опубликованных
портов, ждёт готовности, исполняет `Queries.sql` и останавливает только свой
контейнер. Данные временные, транзакция завершается `ROLLBACK`.

В выводе `|` разделяет колонки, `NULL` обозначает SQL NULL. Блоки соответствуют
опытам на странице `topics/sql.html`. Первые два кода SQLSTATE — ожидаемые
ошибки опытов; остальные запросы прекращают запуск при ошибке.
