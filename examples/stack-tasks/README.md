# Stack · JDK 21

Запуск из этой папки, без сборки и зависимостей:

```bash
java BracketDemo.java
java MonotonicDemo.java
java ExpressionDemo.java
java ValidBrackets.java
java DailyTemperatures.java
java EvalRpn.java
java LargestRectangle.java
```

Проверено на JBR 21.0.11. Три демо дают вывод из урока. Четыре остальных файла — решения задач с проверками из заготовок страницы; ошибка завершает запуск с `AssertionError`.

`BracketDemo`: равные количества не доказывают порядок вложенности; ожидаемые закрывающие символы снимаются с вершины; использование разных концов `ArrayDeque` меняет порядок; пустой `peek` возвращает `null`, пустой `pop` выбрасывает исключение.

`MonotonicDemo`: возвращается индекс первого строго большего значения справа, а не максимум всего суффикса. Равные значения ждут при проходе слева направо и удаляются из будущих вариантов при проходе справа налево. Четыре добавления и три снятия вместо повторных поисков.

`ExpressionDemo`: правый операнд снимается первым, целочисленное деление идёт к нулю, переполнение считается ошибкой. Перевод в постфиксную запись получает корректное выражение, заранее разбитое на токены; бинарные операторы `+ - * /` левоассоциативны, скобки поддерживаются. Токенизация, проверка полной грамматики и унарный минус как отдельный оператор — отдельные этапы. Отрицательный числовой токен вроде `-11` поддерживается.

`LargestRectangle`: высоты неотрицательные, ширина каждого столбца 1, ответ `long`; вход сохраняется. Виртуальный ноль в конце завершает все ожидания, не занимая слот стека. Равная высота снимается, чтобы в стеке оставались строго возрастающие значения; более поздний равный столбец впоследствии охватит весь общий диапазон.

Все входы не `null`. `ValidBrackets` принимает только шесть скобочных символов. `DailyTemperatures` допускает произвольные `int`, в том числе отрицательные, и пустой вход. `EvalRpn` явно проверяет недостаток операндов, число итоговых результатов, формат чисел, деление на ноль и диапазон `int` каждого результата.

Печать содержимого стека в демо — диагностическая обвязка. Оценки O(n) на странице относятся к алгоритму без этой печати.
