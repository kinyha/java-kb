# Stream API demos

Примеры к теме Java › Stream API. JDK 21, без зависимостей.

```bash
cd examples/streams
java LazyDemo.java           # ленивость, порядок обработки, sorted как барьер, count без конвейера, reduce
java -Xmx2g CostDemo.java    # стрим против цикла: массивы, обёртки, короткие списки
```
