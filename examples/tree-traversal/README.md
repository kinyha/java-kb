# Tree Traversal · JDK 21

Из этой папки, без сборки и зависимостей:

```bash
java OrderDemo.java
java BreadthDemo.java
java QueriesDemo.java
java Inorder.java
java Levels.java
java ValidBST.java
java Lca.java
```

Проверено на JBR 21.0.11. Каждый файл самостоятельный, содержит свой Node. Вход — конечное двоичное дерево без циклов и общего ребёнка, его связи во время обхода стабильны. Методы связи не меняют. sample: корень8, дети3 и10, у3 дети1 и6. В трассе стека первый элемент — вершина; в трассе очереди первый элемент — следующий на извлечение.

OrderDemo показывает три момента рекурсивного DFS и тот же inorder с явным стеком; postorder хранит отложенное действие emit. Не-BST выдаёт несортированный inorder. Цепочка10 000 обрабатывается итеративно; предел рекурсии не измеряется и зависит от стека JVM.

BreadthDemo фиксирует size на начало уровня и показывает смешанную очередь между извлечениями. ArrayDeque отвергает null. Глубина считается в узлах: пустое дерево0, лист1. Для minimum depth нужна дорога до листа, пустой ребёнок такой дорогой не является.

QueriesDemo сравнивает локальные условия на детей с глобальными границами предков. Границы long открытые, ключи int, дубли в BST запрещены. Два варианта LCA имеют разные условия: lcaAssumingPresent получает обещание о наличии обеих целей; lcaChecked доказывает наличие через карту родителей по личности объектов. Одинаковые values не заменяют совпадение ссылок.

Четыре задачи содержат решения и проверки страницы. Ошибка завершает запуск AssertionError. Проверки включают пустые деревья, повторы, пропущенные ветки и цепочки10 000 без рекурсивного обхода. До запуска снимаются исходные ссылки left/right; после проверяется их неизменность. Lca сравнивает результат с ожидаемым исходным объектом. Память обвязки проверок не входит в оценки самих алгоритмов.
