# Trees: путь, форма и правило ветвления

Из корня репозитория на JDK 21:

```sh
java examples/trees/BstDemo.java
java examples/trees/RedBlackDemo.java
java examples/trees/BTreeDemo.java
java examples/trees/TrieDemo.java
java examples/trees/OrderedMapDemo.java
```

Зависимости и сборка не нужны. Проверено на JBR 21.0.11+10-b1163.116.
Высота в демо — число узлов на длиннейшем пути: у пустого дерева 0, у листа 1.

- BstDemo: поиск 7 и отсутствующего 9, замена 6 без добавления узла; четыре
  порядка обхода и диапазон [5,11]; удаление 8 с двумя детьми, затем листа 2
  и узла 12 с одним ребёнком. При удалении корня преемник 10 переносится вместе
  с его значением P10. Последние два построения показывают высоту 31
  при последовательных вставках и 5 при вставках медиан того же набора.
- RedBlackDemo: учебная LLRB-вставка, не реализация TreeMap. B означает чёрный,
  R — красный, точка — пустую ссылку NIL. Трассировка вставки 1 после 3 и 2
  показывает два красных подряд, правый поворот, смену цветов, чёрный корень.
  После 1000 последовательных вставок height=10, blackHeight=10; в счётчик
  чёрной высоты включён NIL. Проверка обнаруживает разную чёрную высоту,
  двух красных подряд и правую красную связь. Удаление не реализовано.
- BTreeDemo: множество целых ключей без значений. Минимальная степень t=2,
  максимум три ключа в узле. Перед добавлением 4 полный корневой лист
  [1,2,3] разделяется с подъёмом 2; далее 4 вставляется в правый лист.
  После вставки 1..7 форма [2,4]{[1],[3],[5,6,7]}. Это B-дерево, не B+:
  медиана покидает лист и хранится во внутреннем узле. Удаление не реализовано.
- TrieDemo: общий путь PAY не означает наличие слова PAY. Добавление terminal
  делает слово точным ключом. Его удаление сохраняет PAYOUT; удаление PAYOUT
  не повреждает PAID. Пустая строка отмечает корень. Используются char
  (UTF-16), а дети хранятся в TreeMap; это не массив прямого доступа.
- OrderedMapDemo: BigDecimal 1.0 и 1.00 имеют equals=false, но compareTo=0,
  поэтому занимают одну запись TreeMap. Диапазон — живое представление:
  удаление через subMap меняет исходную таблицу, вставка вне границ
  бросает IllegalArgumentException.

Полные строки вывода показаны частями на [странице](../../topics/trees.html).
Счётчики пути и высоты показывают работу модели, не измеряют наносекунды.
Учебные структуры предназначены для последовательного доступа в одном процессе.
Для прикладного кода нужны готовые коллекции и подходящее хранилище.
