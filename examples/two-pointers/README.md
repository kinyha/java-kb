# Two Pointers · JDK 21

Каждый файл запускается отдельно из этой папки, без сборки и зависимостей:

```bash
java PairDemo.java
java InPlaceDemo.java
java MergeDemo.java
java TwoSumSorted.java
java ReverseArray.java
java RemoveDuplicates.java
java MergeSorted.java
java ThreeSum.java
```

Проверено на JBR 21.0.11. Три `*Demo.java` дают вывод из урока; остальные файлы — решения пяти задач с проверками из заготовок страницы. Ошибка проверки завершает запуск с `AssertionError`.

`PairDemo`: семь проверок перебора и четыре проверки указателей; нарушение сортировки теряет существующую пару; одна и две одинаковые суммы; переполнение `int`.

`InPlaceDemo`: разворот виден через другую ссылку; после удаления дублей меняется длина ответа, физический хвост остаётся; ограничение до двух копий сравнивает с уже собранным ответом.

`MergeDemo`: равные суммы сохраняют порядок левой выгрузки перед правой; запись с конца сохраняет непрочитанные данные; ноль может быть настоящей суммой; первая запись наивного слияния вперёд затирает исходный элемент.

Предусловия: аргументы не `null`. Поиск пары, уплотнение и слияние получают массивы, отсортированные по возрастанию с допустимыми повторами. При слиянии в существующий массив первые `m` элементов первого и первые `n` второго являются данными, массивы разные, в первом хватает места. Проверка этих предусловий в демо не добавлена: на странице явно разобрано, что произойдёт при нарушении сортировки или направления записи.

Задача `ThreeSum` принимает произвольный порядок, сортирует копию и возвращает уникальные тройки значений в лексикографическом порядке. Во всех числовых сравнениях сумм расширение до `long` выполняется до сложения.
